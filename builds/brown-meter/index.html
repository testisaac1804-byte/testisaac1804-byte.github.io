What it is

A live, public brownness meter: one big orb, a 0-100 percentage, and a word that says what the number means — from 'nothin brown here' to 'MAXIMUM BROWN'. It updates itself on every open screen the moment the owner moves it: log in at /admin, push the slider, and every watcher's tab changes on its own over a server-sent-events stream, no refresh. 8 bands x 8 words = 64 phrasings, each band with its own 'as brown as ___' comparator and rotating flavour lines (75% still reads ouuuu). Plus today's + all-time peak records (breaking one flashes NEW PEAK), a public reaction bar (ouuuu / meh / i'm dead — one tap per visitor per minute, counts pushed live), and an optional 'vibe mode' where the hourly cron drifts the meter 1-9% on its own. Installable (inline SVG icon + manifest) and shareable (og: preview tags). One worker.js, zero dependencies, 173/173 assertions. Built after the class in-joke Netlify page of the same name could not be found — so it was made instead.

The Brown Meter — a live brownness meter on a Cloudflare Worker

A public page that shows exactly how brown something is, on a 0-100 scale: one big icon, a percentage, and a word that says what that number means. The owner logs in at /admin and pushes the slider — and every open screen changes by itself, over a server-sent-events stream, with no refresh.

Live

  • App: https://brown-meter.isaac1804.workers.dev
  • Admin: /admin — password-gated (credentials kept out of the repo, 0600 file on disk)
  • Backend: Cloudflare Worker brown-meter + KV namespace BROWN
  • Free tier only: no card, no build step, no dependencies — one worker.js file.

Where it came from

The original job was to find someone else's Netlify page called "Brown Meter" — a class in-joke whose exact URL could not be recovered. Rather than keep hunting for a link, the meter was built properly, on Isaac's own domain, and it came out better than the joke.

What it does

  • 8 bands, 64 words. Every band has eight phrasings, its own "as brown as ___"

    • comparator and rotating flavour lines — nothin brown here → a hint of beige → hmm → ohh → ohhhh → ouuuu → OUUUUUU → MAXIMUM BROWN. The canonical word is biased to the front of the rotation so 75% still reads ouuuu.

  • Live, not polled. /api/stream is a real SSE endpoint; a change is pushed to every

    • viewer in the same tick. Clients reconnect + fall back to polling if the stream dies.

  • Records. Today's peak and the all-time peak are tracked in KV. Beat one and a

    • "NEW PEAK!" flash drops onto the public page.

  • A public reaction bar. Visitors tap ouuuu / meh / i'm dead; counts push live to

    • everyone. One tap per visitor per minute (hashed IP + 60 s cooldown, 429 with a countdown), and the client never gets to name the counter.

  • Vibe mode. Optional hourly cron tick that drifts the meter 1-9% on its own,

    • bouncing between 8% and 97% instead of sticking to a wall. Off by default — when it is off the cron costs a single read and does nothing.

  • Installable + shareable. Inline SVG icon, web manifest, og: link-preview tags.
  • Honest admin panel. Slider + presets, nudge buttons, 🎲 surprise me, undo (a real

    • toggle, not a fake stack), a recent-changes list, and a wipe button for the reactions.
