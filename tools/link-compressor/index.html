Putting the token in unlocks the rest: unlimited links (no hourly limit at all), custom names, the click/creator logs above, the full list from every device, and deleting. Paste it once; it is stored only in this browser (localStorage) and never sent anywhere except this site's own Worker.

How it works / API
  • POST /api/links {"url":"…","slug":"optional"} → {"short":"https://isaac1804.com/s/xxxxx"}
  • GET /api/links (token) → every link with its click count · GET /api/stats → totals
  • GET /api/links/<code> (token) → who made it + the last 100 clicks · GET /api/activity (token) → newest creations + clicks
  • GET /s/<code> → 302 to the target and logs the click · DELETE /api/links/<code> (token) deletes
  • Codes use a 31-character alphabet with no 0 O 1 l i, so they survive being read out loud or typed off a screen. A repeated link returns the code it already has.
  • Click logs record IP, city/country, ISP, device and referer — kept only on this site's own Worker, readable only with the token.
